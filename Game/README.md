# Game

The `Rashmipp/` folder contains the Unity WebGL export copied from
`/Users/rashmiranjan/Desktop/Rashmipp`. It includes the web player page,
Unity loader, WebAssembly build, data file, and loading screen assets.

The website embeds `Rashmipp/index.html` in the Game frame. Open that file
directly to run the game through a local web server.

This is the playable WebGL export, not the original Unity project. The C#
scripts and Unity scene/project files were not present in the Desktop folder.
